# Deep Learning Plan

Do not just copy the programs.

For every topic follow this cycle:

1. Read the explanation.
2. Type the code yourself.
3. Run it.
4. Predict the output before running.
5. Change one thing.
6. Run it again.
7. Explain the code in your own words.
8. Write one program without looking.

## Interview checkpoints

### Functions
- What is a function?
- Difference between parameter and argument?
- What does `return` do?
- What are `*args` and `**kwargs`?

### Callback
- Why can a function be passed as an argument?
- Why do we write `callback` instead of `callback()` while passing it?

### Closure
- What value does the inner function remember?
- Why does the returned function still know `n`?

### Decorator
- What does `@decorator` mean?
- Why do we use a wrapper?
- Why are `*args` and `**kwargs` useful in generic decorators?

### OOP
- What is a class?
- What is an object?
- What is `self`?
- What is `__init__()`?
- What is inheritance?
- What is encapsulation?
- What is abstraction?
- What is operator overloading?
